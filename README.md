# Max’s Delicatessen Website

A modern, fast, and fully responsive web application built for **Max’s Delicatessen** located in Wayne, NJ. The site provides customers with quick access to daily specials, full catering options, direct telephone contact, and online third-party delivery options[cite: 1].

## 🚀 Live Demo
🌐 **[View Max's Deli Live Site](https://themaxsdeli.com)**

---

## ✨ Features & Enhancements

* **Dynamic Navbar**: Modern, responsive fixed navigation bar[cite: 1, 3] with high-contrast typography, brand logo integration[cite: 1], and a collapsed mobile hamburger menu for seamless navigation on small screens.
* **Online Delivery Integration**: Direct single-tap ordering links for Grubhub, UberEats, and DoorDash[cite: 1] with custom-fitted logo badges.
* **Hero Banner / Jumbotron**: High-impact main header featuring a prominent "Browse Now" call-to-action button[cite: 1].
* **Interactive Image Carousel**: Showcase of signature sandwiches, salads, bagels, and specials[cite: 1].
* **Feature Cards**: Highlighted sections for Today's Specials, Online Ordering, and Third-Party Delivery[cite: 1].
* **Dynamic Back-to-Top Button**: Smart scroll floating action button that automatically appears when users scroll past 75% of the page.
* **Centered Footer**: Balanced footer layout[cite: 1] featuring business contact details, hours of operation, embedded Google Maps[cite: 1], and developer credit.
